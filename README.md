# Видимость серверов — Revenge Classic

Экспериментальный плагин для Revenge Classic. Список серверов считывается локально; настройки позволяют скрывать серверы в боковом списке, не выходя из них.

Совместимость с конкретной версией Discord не проверена на устройстве. Если список не найден или не меняется, отключите плагин и перезапустите Discord. Скрытие не является средством приватности и не отключает уведомления.

## Установка

В Revenge откройте Plugins → + и вставьте прямую ссылку на папку этого репозитория через raw.githubusercontent.com, заканчивающуюся на слэш. Затем перезапустите Discord и откройте настройки плагина.
